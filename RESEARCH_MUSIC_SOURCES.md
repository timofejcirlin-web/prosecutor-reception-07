# Sources for requested Soviet melodies

- Marxists Music of the Soviet Union: https://www.marxists.org/history/ussr/sounds/index.htm
- The page provides a direct MIDI for the Soviet National Anthem: https://www.marxists.org/history/ussr/sounds/misc/Anthem.midi
- It also links a 1942 songbook with scores: https://www.marxists.org/history/ussr/culture/music/songs-from-soviet-union.pdf
- Search results also identified a free-use score page for Polyushko Pole: http://balalaika.org.ru/polushko-pole.htm

The current music-generation MCP explicitly forbids putting song titles in generation prompts, so exact melody conversion should use sourced MIDI/score material plus deterministic synthesis/arrangement rather than asking the model to imitate titles directly.
